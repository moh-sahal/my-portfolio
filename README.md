# Mohammed Sahal — Digital Marketing Portfolio

A static, responsive HTML portfolio website. The main page is `index.html`; the page's images are embedded in the HTML, so no separate image assets are required.

## Deploy with GitHub Pages

1. Sign in to GitHub and create a new repository. For a personal portfolio, a repository named `YOUR-USERNAME.github.io` is a convenient option. Otherwise, use any repository name and select that repository's Pages settings.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. GitHub will show the published website URL in the Pages section.

## Update the site

Edit `index.html` locally or use GitHub's web editor, then commit the changes to the `main` branch. GitHub Pages will redeploy automatically.

## Notes

- This is a static website; it does not require Node.js, a build step, or a server.
- The site loads Google Fonts from Google Fonts, so those fonts require an internet connection. System fallback fonts are used if they cannot load.
- Before publishing publicly, review any contact details, campaign figures, client names, and case-study claims to ensure you have permission to share them.
